Proyecto destacado

Golden Booking

Plataforma web de reservas · Full Stack

Sistema de reservas para un club: espacios deportivos por horas y habitaciones de hotel por noches, con un panel de administración y un portal para clientes.

  • API REST con Spring Boot, Spring Security y autenticación JWT con refresh token.
  • Roles de administrador y cliente: aprobar, cancelar y reprogramar reservas.
  • Notificaciones en tiempo real con WebSocket (STOMP) y correos automáticos.
  • Reportes de reservas e ingresos descargables en Excel y PDF.
  • 24 suites de pruebas de extremo a extremo con Cypress.
  • Despliegue: frontend en Vercel y backend en AWS EC2 con HTTPS y respaldos diarios de MongoDB.
